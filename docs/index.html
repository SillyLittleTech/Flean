Flean

Fandom. Leave. Everyone. Alone. Now.

A Swift Extension to convert Yucky Fandom URLs to Breezewiki URLs.

Download (macOS/iOS) View on GitHub

Flean is a small Safari Web Extension with native host helpers that seamlessly redirects visits from mainstream wiki pages to independent breezewiki. Enjoy an ad-free, and privacy-friendly browsing experience without the clutter.

IndieWikiBuddy

Native Integration

Built as a Swift Extension for Safari, featuring native host helpers for macOS and iOS to ensure seamless system integration and fast performance.

Privacy-Friendly

Redirects are calculated dynamically and locally. Flean maps original paths to Breezewiki domains so you can bypass tracking and bloated pages.

Highly Customizable

Manage your own ignore and allow lists, toggle an "ask on visit" confirmation prompt, and easily select your preferred mirror right from the extension popup. The code is easy to edit too!
