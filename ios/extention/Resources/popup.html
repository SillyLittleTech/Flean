Flean
Redirects to independent wikis when available; Breezewiki mirrors as fallback

Independent (self-hosted) wikis are always preferred when available. This mirror is only used when no independent wiki is found.

When enabled you'll be prompted on each redirect; when disabled hosts in the Ignore list will be allowed through without prompting or redirection.

Ignore list (hosts)

Add a fandom host (e.g. deltarune.fandom.com) to ignore redirection and always allow visiting the Fandom site.
